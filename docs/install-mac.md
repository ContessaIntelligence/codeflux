# CodeFlux macOS 下载与安装手册

适用于 Apple 芯片（M1、M2、M3、M4 等）的 Mac。目前只发布 Apple 芯片版本，Intel 芯片的 Mac 暂不支持。

> 查看自己的 Mac 是什么芯片：点屏幕左上角的苹果菜单，选"关于本机"，"芯片"一栏显示 Apple M 开头即可。

CodeFlux 的 Mac 版目前**没有经过 Apple 公证**，所以用浏览器下载后直接双击，系统会提示"无法打开"或"已损坏"。这不是文件有问题，按下面任意一种方式安装即可。

## 方式一：一行命令安装（推荐）

1. 打开"启动台"里的"终端"（或用聚焦搜索 Terminal）。
2. 复制下面这行命令，粘贴到终端，按回车：

```bash
curl -fsSL https://github.com/ContessaIntelligence/codeflux/releases/latest/download/install-mac.sh | bash
```

3. 等待下载完成。脚本会自动把 CodeFlux 安装到"应用程序"，并打开它。

命令行下载的文件不会被系统标记为"来自互联网"，所以不会出现安全提示。以后升级，重新执行同一行命令即可，会覆盖旧版本，你的设置和会话不受影响。

## 方式二：手动下载安装

适合不想使用终端的用户，但需要在"系统设置"里多点几步。

1. 打开 CodeFlux 的发布页：<https://github.com/ContessaIntelligence/codeflux/releases/latest>
2. 在 Assets 里下载 `CodeFlux-mac-arm64.app.tar`。
3. 双击下载好的文件解压，得到 `CodeFlux.app`。
4. 把 `CodeFlux.app` 拖进"应用程序"文件夹。
5. 双击打开。系统会弹出提示，点"完成"或"取消"关掉它。
6. 打开"系统设置 → 隐私与安全性"，滚动到最下面，找到"已阻止使用 CodeFlux"，点"仍要打开"，再输入开机密码确认。
7. 之后可以正常双击使用，这个确认每个版本只需做一次。

如果第 5 步提示的是"CodeFlux 已损坏，无法打开"，改用下面一条命令去掉标记：

```bash
xattr -cr /Applications/CodeFlux.app
```

执行后再双击打开即可。

> macOS 15 之后，以前常用的"右键 → 打开"已经不再有效，必须走第 6 步。

## 使用本地模型

CodeFlux 内置了本地模型运行环境，数据不会离开你的电脑。

1. 在供应商选择里点"本地模型"。
2. 第一次使用会提示下载 Qwen3-4B 模型（约 2.6 GB），点"下载"。下载中可以取消，下次会从断点继续。
3. 下载完成后会自动启动并连接，选择 `qwen3-4b` 即可对话。

注意事项：

- 建议 16 GB 内存或以上。8 GB 内存也能运行，但会比较慢。
- 模型保存在 `~/.codeflux/models/`。想释放空间，直接删除这个目录里的 `.gguf` 文件即可。
- 4B 的小模型适合简单问答和小改动，复杂的多步骤任务容易出错，这类任务建议改用云端模型。
- 下载慢或失败时，可以先在浏览器下载 `Qwen3-4B-Q4_K_M.gguf`（Hugging Face 的 `Qwen/Qwen3-4B-GGUF`），放进上面的目录，再回到 CodeFlux 点"本地模型"，会跳过下载直接启动。

## 校验下载文件（可选）

发布页的 `SHA256SUMS.txt` 记录了每个文件的校验值。下载后在终端执行：

```bash
shasum -a 256 ~/Downloads/CodeFlux-mac-arm64.app.tar
```

把输出和 `SHA256SUMS.txt` 里对应的一行对比，一致说明文件完整、没有被篡改。

## 卸载

1. 退出 CodeFlux。
2. 把"应用程序"里的 `CodeFlux.app` 拖进废纸篓。
3. 想彻底清除模型文件，再删除 `~/.codeflux` 目录。

## 常见问题

**提示"无法打开，因为无法验证开发者"**
按方式二的第 6 步，在"隐私与安全性"里点"仍要打开"。

**提示"CodeFlux 已损坏，应移到废纸篓"**
文件没有损坏，是下载时被系统加了隔离标记。执行 `xattr -cr /Applications/CodeFlux.app` 后重新打开，或者改用方式一。

**一行命令提示 `Only Apple Silicon (arm64) builds are published`**
你的 Mac 是 Intel 芯片，目前没有对应版本。

**命令提示 `curl: command not found` 或网络错误**
检查网络能否访问 GitHub。网络不稳定时，可以改用方式二，在浏览器里下载。

**本地模型下载很慢或一直失败**
参考上面"使用本地模型"里的最后一条，手动下载模型文件放进 `~/.codeflux/models/`。

**本地模型回答慢、风扇狂转**
这是模型在本机运行的正常现象。可以关闭其他占内存的程序，或改用云端模型。

## 为什么不能做到双击即用

要让下载后双击就能打开，应用必须使用 Apple 开发者账号（99 美元/年）签名并公证。目前没有这个账号，所以采用上面的方式。后续如果开通了开发者账号，会改为签名公证后的安装包，到时不再需要任何额外步骤。
